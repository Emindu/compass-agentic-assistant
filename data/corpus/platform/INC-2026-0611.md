# INC-2026-0611: Core banking end-of-day batch overran into business hours

> MOCK DATA — fictional incident created for the Compass assessment POC.

## Summary

The core banking end-of-day (EOD) batch, which normally finishes by 04:30, ran until 08:50.
Branches opened with balances from the previous day for 20 minutes. No payment failures.

## Root cause

A storage array firmware upgrade on the previous evening reduced write throughput by 40%. The
interest accrual step, which is write-heavy, took 4 hours longer than usual.

## Action items

- PLT-1201: Storage changes not allowed within 12 hours of EOD
- PLT-1202: Alert if EOD has not finished by 05:30
