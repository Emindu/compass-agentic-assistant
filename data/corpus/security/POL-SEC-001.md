# Information security and access control policy

> MOCK DATA — fictional document created for the Compass assessment POC.

## Data classification

| Level | Examples | Who may access |
| --- | --- | --- |
| Public | Product brochures, public policies | Anyone |
| Internal | Runbooks, architecture, incident reports | All employees |
| Confidential | Risk reviews, audit findings, customer complaints data | Need-to-know, approved by the data owner |
| Restricted | Privileged access procedures, security keys, HR investigations | Named individuals only |

## Access control

- Access is role-based and reviewed quarterly by line managers.
- Privileged access requires a ticket, manager approval and is time-boxed to 8 hours.
- Shared accounts are prohibited.

## Credentials

- Staff must never share passwords or one-time passwords (OTP) with anyone, including IT
  support. IT will never ask for them.
- Report suspected phishing to the Security Operations Centre immediately.
